Fully provisioned via Terraform with CI/CD through GitHub Actions and keyless authentication.

<details>
<summary><b>⚙️ Distributed REST Ingestion — Serverless Spark at Scale</b></summary>
<br/>

> High-throughput ingestion framework parallelizing REST API extraction across Spark executors with BigQuery as the analytical sink.

| Attribute | Details |
|:----------|:--------|
| **Stack** | Dataproc Serverless, PySpark, RDDs, BigQuery, Airflow |
| **Scale** | Massively parallel API calls distributed across executor cores |
| **Performance** | Orders-of-magnitude faster than sequential ingestion |
| **Security** | Secret Manager–backed credentials, VPC-SC aware design |
| **Impact** | Production pipeline powering downstream analytics with fresh data |
| **Repository** | [`serverless-spark-ingestion`](https://github.com/joshianshul2/serverless-spark-ingestion) |

REST endpoints are partitioned and distributed as RDDs so each executor pulls its slice of the API surface concurrently. Results are normalized, validated, and written to BigQuery — eliminating ingestion bottlenecks without managing any cluster infrastructure.

</details>
